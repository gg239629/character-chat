# DeepSeek V4.1 Flash 缓存测试

测试日期为 2026-11-20，使用 DeepSeek 官方 API 的 `deepseek-flash` 模型。同一组 12 轮合成会议对话，以固定历史回复保证两组输入可比较。旧版来自 a26f309，改进版使用 12,288 token 默认预算。每组在角色请求中使用不同的测试标识，隔离两组前缀。测试使用临时 SQLite，未提交真实对话或密钥。

该案例中，第 2–12 轮追加版都发生缓存命中，命中量随历史追加而增长，第 12 轮为 5,632 / 6,032 token。输入量较旧版多 3,193 token，未命中输入减少 13,703 token。实际费用须按当时的缓存命中、未命中及输出计价计算。

该实验是一组短对话重放。它验证了这条 DeepSeek API 路径能够回报缓存命中；两组先后执行，并非性能或准确率的统计估计。
