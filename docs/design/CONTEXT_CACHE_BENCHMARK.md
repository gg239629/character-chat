# 追加式上下文与 KV cache 实测

测试日期为 2026-11-20。模型为 `gpt-6-luna`，所有请求使用同一 OpenAI 兼容网关。基线来自提交 `a26f309`，每组重放同样的 12 轮合成会议对话。每轮实时生成答复并统计用量，下一轮使用固定的历史回复，避免不同模型输出改变后续输入。第 11 轮检查能否找回团建的取消状态，第 12 轮检查能否找回预约编号。每组使用独立的简短前缀标识。测试使用临时 SQLite 和合成角色资料。

## 正式对照

角色输出上限统一为 320 token。表中的输入用量和命中量来自网关。未命中输入包含角色回复和摘要的总输入，再扣掉已命中的 token。耗时为组装加整条回复的中位数，压缩当轮包含摘要调用。各组为单次重放，部分运行时段重叠，耗时会受到网关负载影响。

| 组合 | 角色输入 | 摘要输入 | 命中输入 | 未命中输入合计 | 输出合计 | 中位耗时 | 回忆题 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 基线 · 字符滑动窗口 | 61,492 | 0（0 次） | 0 | 61,492 | 394 | 2.80s | 0/2 |

| 追加历史 · 8,192 token · 动态区去重 | 57,497 | 2,942（2 次） | 4,096 | 56,343 | 877 | 4.27s | 2/2 |

采用 **8,192 token 加动态去重**作为默认值。本次该组合答对两道回忆题，最长共同前缀从 2 条消息增加到 12 条，总输入从 61,492 降至 60,439，未命中输入从 61,492 降至 56,343（约 8.4%）。它比 7,168 token 方案多使用 1,893 个总输入 token，但本次多命中 4,096 个 token，并少产生 173 个输出 token。两者均压缩两次。所选方案中位耗时从 2.80 秒增至 4.27 秒。费用取决于网关对普通输入、缓存读取、缓存写入和输出的计价。

基线两题均回答「不确定」。所选组合回答「周六植物园团建已取消，目前暂不安排新地点」和「Q7M9」。第 11 题按所选组合的回复判定正确，原始取消句的逐字匹配标志为 false。第 12 题的原始编号出现在请求中。

## 扩大窗口复测

将默认输入预算调至 12,288 token，历史压缩警戒线调至 90%，单批摘要原文预算调至 3,600 token。同样 12 轮对话的结果如下。

| 指标 | 8,192 token | 12,288 token |
| --- | ---: | ---: |
| 摘要调用次数 | 3 | 0 |
| 最长共同前缀消息数 | 10 | 22 |
| 总输入 token（含摘要） | 59,421 | 65,819 |
| 网关回报的缓存命中 token | 2,048 | 0 |
| 回忆题 | 2/2 | 2/2 |

另用固定 prompt_cache_key 连续发送三次完全相同的 2,488 token 请求，再只改末句发送一次。四次都返回 200，缓存命中均为 0。该对照说明本次零命中可以在请求完全相同时复现，具体原因需要网关或上游日志。

补充测试使用未指定缓存键的 9,913 token 请求，前三次完全相同，第四次只修改末句。四次均返回 200，供应商报告的缓存读取和写入均为 0。此结果无法区分网关转发、上游缓存和用量字段的问题。

## 复跑

用 Git 的归档功能将 `a26f309` 解压到单独目录，作为 `--repo` 的参数。脚本会交互式读取密钥，输出逐轮 JSON。使用不同的 `--trial` 标识可降低不同实验组复用同一前缀缓存的可能。可用 `CHAT_CONTEXT_INPUT_TOKENS` 调整改进组预算。

```powershell
python scripts/benchmark_context.py --repo $env:BASELINE_CHECKOUT --url $env:MODEL_BASE_URL --layout baseline --trial baseline-replay --output baseline.json
python scripts/benchmark_context.py --repo $env:BASELINE_CHECKOUT --url $env:MODEL_BASE_URL --layout tail-first --trial tail-replay --output tail.json
$env:CHAT_CONTEXT_INPUT_TOKENS = '8192'
python scripts/benchmark_context.py --url $env:MODEL_BASE_URL --layout append --trial append-replay --output append.json
```
